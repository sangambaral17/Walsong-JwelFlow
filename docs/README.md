## 🌟 Executive Summary
Walsong JwelFlow is an ultra-luxurious, offline-first ERP solution designed specifically to meet the unique needs of jewelry shops in Nepal. Built with a deep understanding of local business practices like Tola-Masha-Lal weight systems and Dhito (pawn/loan) workflows, JwelFlow modernizes traditional operations without sacrificing familiarity.

## 🚀 Key Features for Stakeholders
1. **Multi-Shop Scalability**: A unique global branding engine allows a single software installation to dynamically customize itself (name, logo, PAN, accent colors, theme) for any specific jewelry shop out of the box.
2. **Offline-First Reliability**: Powered by RxDB (Reactive Database), JwelFlow runs completely offline. This is crucial for areas with unstable internet connectivity while still preventing data loss through robust local indexing.
3. **Immutable Audit Trails**: Every financial action (sales, dhito disbursements, profile updates) is cryptographically tracked in an append-only audit log, ensuring complete IRD compliance.
4. **Role-Based Security**: Built-in access control protects sensitive business intelligence, inventory deletion, and profit margins, ensuring that staff can only access what the shop owner permits via PIN-locks.
5. **Real-time Business Intelligence**: Owners have access to a rich analytics dashboard displaying 7-day revenue trends, daily profit margins, and End of Day (EOD) metrics.

## 🛠 Technology Stack
- **Frontend Engine**: Next.js (App Router), React 18
- **Styling**: Tailwind CSS v4, custom luxury "Midnight & Gold" color system
- **Database**: RxDB (Reactive Database) over IndexedDB
- **Data Integrity**: Immutable tracking, local-first syncing readiness
- **Visuals**: Framer Motion & CSS custom properties for micro-animations
